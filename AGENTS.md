# Правила проекта

- Не добавлять в Markdown дату создания или фиксации документа. Даты публикаций источников и отчётные периоды сохранять, когда они нужны для смысла.
- Рабочий язык backend — Java. Сохранять границы Commerce API, Search API и фоновых обработчиков.
- Основные результаты каждого чекпоинта размещать в README; подробности и воспроизводимые расчёты связывать ссылками.
- Отделять требования, рыночные факты, допущения и результаты измерений.
- Сохранять пользовательские правки и ограничивать изменения текущим этапом.
